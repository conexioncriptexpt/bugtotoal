# RCA — Redeploy blocked (run 1535e4fc-2f70-4f65-9dac-111e5f7b5512)

## Problem statement
A redeploy of `conex-assist-1` (https://conex-assist-1.emergent.host) was triggered automatically. The `trigger_indie` step returned HTTP 409 `deployment_blocked` and the run never went live.

## What I found
- `describe_deployment_state`: the failed run `1535e4fc-...` is a `redeploy`, status `failed`, with error:
  `await_phishing: ... deployment blocked: there has been an error with this deployment. Please fork the session and start a new deployment ... deployment blocked`
- `get_step_status` for the failed run:
  - `wakeup_environment` → success
  - `build` → **success** (the image built fine)
  - `mongodb_migrate`, `manage_secrets`, `deploy`, `health_check` → all "not run: an earlier deploy step failed"
- The trigger itself returned: `status 409 {"code":"deployment_blocked","error":"This deployment was blocked. If you believe this is a mistake, please contact support."}` with `retryable: false`.

## Root cause
The deployment was stopped at the platform's **phishing/abuse classification gate** (`AwaitPhishingClassification`). This is a server-side block on the deployment, not a fault in the app's source, manifests, secrets, tier, or infrastructure. The build succeeded; the pipeline was halted administratively.

## Why I did not resume
The 409 `deployment_blocked` is explicitly `retryable: false`. Re-firing the pipeline would hit the same block. There is no manifest or source change that lifts an abuse/phishing classification — it must be cleared by Emergent support (or by forking the session into a new deployment as the platform message suggests).

## Suggested fix
- **User → contact support:** File an Emergent support ticket quoting deployment_id `7b10ae89-d5e8-43c6-a2d5-9a56b1b45faf`, job_id `9161239e-a9d5-4804-af8c-f687a0a918db`, and failed run_id `1535e4fc-2f70-4f65-9dac-111e5f7b5512`, stating the deployment was blocked by the phishing classifier and you believe it is a mistake. Alternatively, fork the session and start a new deployment as the platform message indicates.
